# 测试条件场景物体加载功能

## 概述
我们提供了两个测试脚本来验证条件场景物体加载功能是否正常工作。

## 快速测试（推荐）

### test_scene_simple.py
这个脚本直接使用你的训练配置文件，最简单快速。

#### 基本用法

```bash
# 使用默认配置（configs/track/train.yaml）
python scripts/test_scene_simple.py

# Headless 模式（无GUI，快速测试，推荐）
python scripts/test_scene_simple.py --headless

# 使用其他配置文件
python scripts/test_scene_simple.py --config-dir ./configs/track --config-name eval

# 指定设备
python scripts/test_scene_simple.py --headless --device cuda:0
```

## 高级测试

### test_conditional_scene.py
这个脚本允许你直接指定要测试的物体，无需修改配置文件。

#### 基本用法

```bash
# 测试 h_frame（应该有墙）
python scripts/test_conditional_scene.py --object h_frame

# 测试 woodchair（不应该有墙）
python scripts/test_conditional_scene.py --object woodchair

# 测试多个物体（包含 h_frame，应该有墙）
python scripts/test_conditional_scene.py --object h_frame --object woodchair

# Headless 模式
python scripts/test_conditional_scene.py --object h_frame --headless

# 指定环境数量
python scripts/test_conditional_scene.py --object h_frame --num_envs 2
```

#### 注意事项
这个脚本需要找到对应物体的 motion 文件，会在以下目录搜索：
- `./data/datasets/Weave/rollout/train`
- `./data/test`
- `./data/eval`

## 故障排查

### 问题 1: 测试显示"结果异常"

**症状**: 输出显示 "❌ 结果异常：h_frame 场景应该有墙，但没有找到"

**可能原因**:
1. 配置文件中的 motion_files 路径不正确
2. Motion 文件中的 object_name 不是 "h_frame"
3. 代码修改未生效

**解决方法**:
```bash
# 1. 检查配置文件
cat configs/track/train.yaml | grep motion_files

# 2. 检查 motion 文件内容
python -c "import numpy as np; data=np.load('your_motion_file.npz'); print(data['object_name'])"

# 3. 确认代码修改
cat source/g1_hoi_learning/g1_hoi_learning/tasks/hoi/__init__.py | grep -A 5 "_add_conditional_scene_objects"
```

---

### 问题 2: 找不到 motion 文件

**症状**: `FileNotFoundError: Motion文件不存在`

**解决方法**:
```bash
# 查找可用的 motion 文件
find ./data -name "*.npz" -type f

# 使用绝对路径
python scripts/test_scene_simple.py --headless
```

---

### 问题 3: 环境创建失败

**症状**: 环境创建时出错

**解决方法**:
```bash
# 1. 确保依赖已安装
pip install -e source/g1_hoi_learning

# 2. 检查 CUDA 是否可用
python -c "import torch; print(torch.cuda.is_available())"

# 3. 尝试使用 CPU
python scripts/test_scene_simple.py --headless --device cpu
```
