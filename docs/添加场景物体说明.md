# 如何根据物体类型动态添加场景物体

## 概述
在 Weave 项目中，你可以根据加载的物体类型动态添加额外的场景物体。例如，只在加载 `h_frame` 物体时才添加墙。

## 实现方式

### 修改文件位置
`source/g1_hoi_learning/g1_hoi_learning/tasks/hoi/__init__.py`

### 核心实现逻辑

在 `_make_env` 函数中添加了条件判断逻辑：

```python
def _make_env(cfg, **kwargs):
    """Resolve scene.object from motion_files' object_names."""
    from .mdp.commands import MotionLoader

    motion_files = cfg.commands.motion.motion_files
    object_names = MotionLoader.object_names_of(motion_files)
    
    # ... 原有的物体配置代码 ...
    
    # 根据物体类型添加额外场景物体
    _add_conditional_scene_objects(cfg, object_names)
    
    return ManagerBasedRLEnv(cfg=cfg, **kwargs)


def _add_conditional_scene_objects(cfg, object_names: list[str]):
    """根据物体类型添加额外的场景物体（如墙）。
    
    Args:
        cfg: 环境配置
        object_names: 当前场景中的物体名称列表
    """
    # 如果包含 h_frame，添加两堵墙
    if "h_frame" in object_names:
        print(f"[INFO]: Detected h_frame object, adding walls to scene")
        
        cfg.scene.wall_1 = RigidObjectCfg(
            prim_path="{ENV_REGEX_NS}/Wall1",
            spawn=sim_utils.UsdFileCfg(
                usd_path=f"{ASSET_DIR}/h_frame/hframe_wall_mode3.usd",
                scale=(1.0, 1.0, 1.0),
                rigid_props=sim_utils.RigidBodyPropertiesCfg(
                    kinematic_enabled=True,
                    disable_gravity=True,
                ),
            ),
            init_state=RigidObjectCfg.InitialStateCfg(
                pos=[-1.0, -3.0, 0.0],
                rot=[0.0, 0.0, 0.707, 0.707],
            ),
        )
        
        cfg.scene.wall_2 = RigidObjectCfg(
            prim_path="{ENV_REGEX_NS}/Wall2",
            spawn=sim_utils.UsdFileCfg(
                usd_path=f"{ASSET_DIR}/h_frame/hframe_wall_mode3.usd",
                scale=(1.0, 1.0, 1.0),
                rigid_props=sim_utils.RigidBodyPropertiesCfg(
                    kinematic_enabled=True,
                    disable_gravity=True,
                ),
            ),
            init_state=RigidObjectCfg.InitialStateCfg(
                pos=[1.0, -3.0, 0.0],
                rot=[0.0, 0.0, 0.0, 1.0],
            ),
        )
```

## 工作原理

1. **物体检测**: 系统从 motion files 中提取物体名称列表
2. **条件匹配**: 检查是否包含特定物体（如 `h_frame`）
3. **动态添加**: 如果匹配，则动态向场景配置添加额外物体
4. **环境创建**: 带有额外物体的配置用于创建环境

## 添加更多条件规则

你可以在 `_add_conditional_scene_objects` 函数中添加更多规则：

```python
def _add_conditional_scene_objects(cfg, object_names: list[str]):
    """根据物体类型添加额外的场景物体。"""
    
    # 规则1: h_frame 添加墙
    if "h_frame" in object_names:
        print(f"[INFO]: Detected h_frame, adding walls")
        cfg.scene.wall_1 = RigidObjectCfg(...)
        cfg.scene.wall_2 = RigidObjectCfg(...)
    
    # 规则2: woodchair 添加桌子
    if "woodchair" in object_names:
        print(f"[INFO]: Detected woodchair, adding table")
        cfg.scene.table = RigidObjectCfg(
            prim_path="{ENV_REGEX_NS}/Table",
            spawn=sim_utils.UsdFileCfg(
                usd_path=f"{ASSET_DIR}/smalltable/smalltable.usd",
                scale=(1.0, 1.0, 1.0),
                rigid_props=sim_utils.RigidBodyPropertiesCfg(
                    kinematic_enabled=True,
                    disable_gravity=True,
                ),
            ),
            init_state=RigidObjectCfg.InitialStateCfg(
                pos=[0.0, 1.5, 0.0],
                rot=[0.0, 0.0, 0.0, 1.0],
            ),
        )
    
    # 规则3: 多个物体的组合条件
    if "largebox" in object_names or "smallbox" in object_names:
        print(f"[INFO]: Detected box, adding shelf")
        cfg.scene.shelf = RigidObjectCfg(...)
    
    # 规则4: 为所有场景添加通用物体
    # 不加条件判断，直接添加
    cfg.scene.floor_marker = RigidObjectCfg(...)
```

## 配置示例

### 示例1: 仅当加载 h_frame 时添加两堵墙
```yaml
# configs/track/train.yaml
env:
  commands:
    motion:
      motion_files:
        - ./data/datasets/h_frame_motion.npz  # 包含 h_frame
```
**结果**: 场景中会有 h_frame + wall_1 + wall_2

### 示例2: 加载其他物体时不添加墙
```yaml
env:
  commands:
    motion:
      motion_files:
        - ./data/datasets/woodchair_motion.npz  # 不包含 h_frame
```
**结果**: 场景中只有 woodchair，没有墙

### 示例3: 多个物体，包含 h_frame
```yaml
env:
  commands:
    motion:
      motion_files:
        - ./data/datasets/h_frame_motion.npz
        - ./data/datasets/woodchair_motion.npz
```
**结果**: 场景中会有墙（因为包含 h_frame）

## 参数说明

### 位置和旋转
- **pos**: `[x, y, z]` - 世界坐标系中的位置（单位：米）
- **rot**: `[x, y, z, w]` - 四元数表示的旋转

#### 常用旋转四元数：
- 无旋转：`[0, 0, 0, 1]`
- 绕Z轴旋转90度：`[0, 0, 0.707, 0.707]`
- 绕Z轴旋转180度：`[0, 0, 1, 0]`
- 绕Y轴旋转90度：`[0, 0.707, 0, 0.707]`

### 物理属性
- **kinematic_enabled**: 
  - `True` - 静态物体，不受物理力影响（适合墙、地板）
  - `False` - 动态物体，受物理引擎控制
  
- **disable_gravity**: 
  - `True` - 不受重力影响
  - `False` - 受重力影响

### 其他物理配置

```python
# 完整的物理属性配置示例
rigid_props=sim_utils.RigidBodyPropertiesCfg(
    kinematic_enabled=True,        # 静态/动态
    disable_gravity=True,          # 禁用重力
    linear_damping=0.0,           # 线性阻尼
    angular_damping=0.0,          # 角阻尼
    max_linear_velocity=1000.0,   # 最大线速度
    max_angular_velocity=1000.0,  # 最大角速度
)

# 质量配置
mass_props=sim_utils.MassPropertiesCfg(
    mass=2.0,                     # 直接指定质量（kg）
    # 或使用密度（二选一）
    # density=200.0
)

# 碰撞配置
collision_props=sim_utils.CollisionPropertiesCfg(
    contact_offset=0.005,         # 碰撞偏移
)
```

## 注意事项

1. **物体名称匹配**: 确保条件中使用的名称与 `OBJECT_CFG_BY_NAME` 中的键一致
2. **prim_path 唯一性**: 每个额外物体的 `prim_path` 必须唯一
3. **碰撞检测**: 确保额外物体不与主物体或机器人初始位置重叠
4. **性能影响**: 大量额外物体会影响仿真性能，特别是在多环境并行时
5. **ENV_REGEX_NS**: 使用此占位符确保每个并行环境都有独立的物体实例

## 常见问题

**Q: 为什么我的墙没有出现？**
A: 检查 motion file 中的物体名称是否为 "h_frame"，可以通过日志查看实际加载的物体名称。

**Q: 可以为不同环境添加不同的墙吗？**
A: 目前的实现为所有包含 h_frame 的环境添加相同的墙。如需环境级别的差异，需要修改 `MultiAssetSpawnerCfg` 逻辑。

**Q: 如何添加动态物体而不是静态墙？**
A: 将 `kinematic_enabled` 设置为 `False`，`disable_gravity` 设置为 `False`，并配置 `mass_props`。

**Q: 可以根据其他条件（非物体类型）添加场景物体吗？**
A: 可以，你可以在 `_add_conditional_scene_objects` 中访问 `cfg` 的任何属性来做条件判断。
